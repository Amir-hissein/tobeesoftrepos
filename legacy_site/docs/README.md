# TOBEESOFT - Site Web Officiel

Site web professionnel pour TOBEESOFT, spécialiste en développement logiciel et numérisation des infrastructures technologiques.

## 🚀 Démarrage Rapide

### Option 1 : Ouvrir directement
Double-cliquez sur `index.html`

### Option 2 : Serveur local (recommandé)
```bash
# Avec Python 3
python3 -m http.server 8000

# Ou avec Node.js
npx serve
```

Puis ouvrez : `http://localhost:8000`
